# shuai-nav · 网址导航

一个静态网址导航站：**数据与页面完全分离**，改数据不用碰代码。
站点同时收纳「外部来源的单文件 HTML 文档」，每份文档一个目录。

```
shuai-nav/
├── index.html          网址导航页（站点首页）
├── assets/
│   ├── style.css       样式（沿用博客 latex-minimal 主题的配色与字体）
│   └── app.js          渲染 / 搜索 / 标签筛选 / 明暗主题
├── data/
│   └── sites.js        ★ 数据源：所有网址都在这里
├── nav/
│   └── tianhe/         单文件文档，一份文档一个目录
│       └── index.html
└── favicon.svg / favicon.ico
```

## 怎么用

访问 https://shuai-nav.pages.dev/ 即可打开。

本地预览：仓库根目录起一个静态服务器即可，例如 `npx serve .`
或 `python -m http.server 4000`，然后访问 http://localhost:4000/。

## 怎么加一条网址

只改 `data/sites.js`。在对应分类的 `items` 数组里加一行：

```js
{
  "t": "站点名称",              // 显示的标题
  "u": "https://example.com",  // 网址
  "g": ["标签1", "标签2"]      // 标签，用于页面上的筛选
}
```

保存后刷新页面即可生效。副标题里的「N 条网址 / N 个分类」是页面运行时统计的，不用手动维护。
改完数据顺手把 `meta.updated` 更新为当天日期。

### 新增一个分类

在 `categories` 数组里加一项：

```js
{
  "key": "mycat",              // 英文标识，小写，页面内部用
  "name": "我的分类",           // 显示名
  "desc": "这个分类是干什么的",  // 分类下的一句话说明
  "items": [ /* 网址，同上格式 */ ]
}
```

## 怎么加一份独立文档

1. 把单文件 HTML 放到 `nav/<slug>/index.html`（`<slug>` 用小写英文，如 `tianhe`）
2. 在 `data/sites.js` 的「独立文档」分类里加一条，`u` 填站内相对路径：

```js
{
  "t": "文档标题",
  "u": "/nav/<slug>/",
  "g": ["标签1", "标签2"]
}
```

该分类固定排在第一位，访问地址即 `https://shuai-nav.pages.dev/nav/<slug>/`。

## 标签怎么用

标签是自由文本，页面上会按当前分类自动统计并显示（带出现次数）。
点标签 = 叠加筛选，再点一次取消。多个标签之间是「同时满足」。

想统一标签写法，直接改 `g` 里的字符串即可，页面不需要改。

## 页面功能

- **分类切换**：左侧（手机上是顶部的横向胶囊）按分类筛选
- **全文搜索**：搜索标题、网址、标签；按 `/` 聚焦搜索框，`Esc` 清空
- **标签筛选**：点击标签叠加过滤
- **明暗主题**：右上角切换，选择会记在浏览器 localStorage 里
- **URL 同步**：当前筛选状态写进地址栏 hash，可以直接分享/收藏某个筛选结果

## 部署

Cloudflare Pages 连接本仓库自动部署：

| 配置项 | 值 |
| --- | --- |
| 生产分支 | `main` |
| Build command | 留空 |
| Build output directory | `/` |

推送到 `main` 即触发部署，无需本地构建。

## 数据是怎么来的

导航数据整理自浏览器导出的 `bookmarks.html`（Netscape 书签格式），处理规则：

1. 按 URL 去重（原文件末尾有一批重复导出）
2. 剔除**死链**（实测 HTTP 404 / 域名解析失败 / 持续 5xx）
3. 剔除**内网与校内私有地址**（`192.168.*`、`10.*`、教务系统、职教云、超星教学平台等）
4. 剔除**工作私有链接**（腾讯文档、金山文档表单、腾讯云采购页等）
5. 重新设计分类体系（原「软件技术 / 发现应用 / 设计 / 学业 / 生活 …」重组为导航站分类）
6. 标签收敛成一套受控词表（原书签里有 200+ 个碎标签，筛选器没法用）

> 探活时间：见 `data/sites.js` 里的 `meta.updated`。站点改版或下线后失效的链接需要手动复检。
> 想知道某条链接为什么被删，可以对着原始 `bookmarks.html` 查。
